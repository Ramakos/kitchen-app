## Color Tokens

Semantic tokens only — **never hardcode raw colors in components.**
All values are declared in each app's `src/index.css` as HSL CSS variables and referenced in `tailwind.config.{ts,js}`.

### Light Theme

| Token | HSL | Use |
|---|---|---|
| `--background` | `0 0% 100%` | Page background |
| `--foreground` | `0 10% 12%` | Primary text |
| `--card` | `0 0% 100%` | Cards, panels |
| `--card-foreground` | `0 10% 12%` | Text on cards |
| `--primary` | `2 73% 46%` | Brand red — buttons, active states |
| `--primary-foreground` | `0 0% 100%` | Text on primary |
| `--secondary` | `2 40% 96%` | Soft red-tinted surfaces |
| `--secondary-foreground` | `2 60% 28%` | Dark red text |
| `--muted` | `0 15% 96%` | Subtle surfaces |
| `--muted-foreground` | `0 5% 42%` | Secondary / placeholder text |
| `--accent` | `2 45% 95%` | Hover states, highlights |
| `--accent-foreground` | `2 60% 28%` | Text on accent |
| `--destructive` | `0 84.2% 60.2%` | Errors, overdue alerts, voids |
| `--destructive-foreground` | `0 0% 100%` | Text on destructive |
| `--border` | `0 15% 90%` | Borders |
| `--input` | `0 15% 90%` | Input borders |
| `--ring` | `2 73% 46%` | Focus rings |

### Dark Theme

Backgrounds shift to `0 10% 7%`–`0 10% 10%`; primary red lifts to `2 72% 54%` for contrast.
Dark theme is toggled via the `.dark` class (`darkMode: ["class"]` in Tailwind config).

| Token | Dark HSL |
|---|---|
| `--background` | `0 10% 7%` |
| `--foreground` | `0 0% 95%` |
| `--card` | `0 10% 10%` |
| `--primary` | `2 72% 54%` |
| `--border` | `0 10% 18%` |

## Typography

- **Font:** System font stack — no custom webfont, keeps builds lean on 3 GB RAM hardware.
- **Scale:** `text-xs` / `text-sm` for metadata; `text-base`+ for primary content.
- **Headings:** Single `<h1>` per page; page titles use `font-semibold tracking-tight`.
- **KDS / POS:** compact sizing; ticket item names at `text-base`, quantity/time at `text-xs`.

## Layout Principles

| Context | Principle |
|---|---|
| **General** | Compact Professional — high-density, tight spacing (`gap-2`, `py-2`), shadcn/ui components |
| **Counter / Admin POS** | Desktop-first; Classic stacked or Modern mode via `useLayoutPreference`; collapsible icon-only sidebar |
| **Worker App** | Mobile-first shell (`max-w-lg`), large tap targets >= 40 px, tab-based nav: Orders / Pocket / My Shift |
| **Kitchen (KDS)** | Card grid; urgency color shift at 5 min (`--accent`), 10 min (`--destructive` + pulse animation) |
| **Express Order** | Customer-facing; clean full-width layout, large readable type, minimal chrome |
| **PWA / Installable** | Safe-area insets (`env(safe-area-inset-*)`), standalone display mode, no address bar chrome |

## Component Conventions

- **UI Primitives:** shadcn/ui, themed exclusively through the CSS variables above — do not override with raw Tailwind color utilities.
- **Dialogs / Toasts:** No native `alert()` / `confirm()` — use `sonner` toasts and `<Dialog>` components.
- **Buttons:**
  - `variant="default"` (brand red) — primary / confirmatory actions
  - `variant="outline"` / `variant="ghost"` — secondary actions
  - `variant="destructive"` — voids, refunds, deletions
- **Badges:** order type, order status, UNPAID markers, out-of-stock cues.
- **PIN Inputs:** 4-digit, large touch targets, no copy-paste, masked by default.

## PWA Guidelines

All apps (except Counter App which is desktop-first) should be installable PWAs.

| Asset | Spec |
|---|---|
| `public/manifest.json` | `name`, `short_name`, `theme_color: "#CA251F"`, `background_color: "#fff"` |
| Icons | 192 x 192 px and 512 x 512 px PNG from mascot mark |
| Service Worker | Vite PWA plugin (`vite-plugin-pwa`) — cache-first for static assets, network-first for Supabase API |
| `<meta name="theme-color">` | `#CA251F` (light) / `#1a0a09` (dark) |
| Display mode | `standalone` |
| Offline fallback | `/offline.html` — branded page with logo and "You are offline" message |

## Accessibility & Performance

- Focus rings use `--ring` (brand red) — visible on all interactive elements.
- Semantic HTML with descriptive `alt` text on all images; `<img>` tags include explicit `width` / `height`.
- No heavy animations — `prefers-reduced-motion` respected.
- Offline-first caching (IndexedDB / Dexie) for Worker and Counter apps.
- Lighthouse PWA score target: >= 90.
